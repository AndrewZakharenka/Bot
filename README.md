# A1 Voice Bot

Учебный проект: консольный голосовой бот на Python.

## Стек (финальная цель)
- **Whisper** — распознавание речи с микрофона
- **OpenAI GPT** — генерация ответов
- **pyttsx3** — синтез речи (TTS)

## Прогресс

| День | Тема |
|------|------|
| День 1 | Переменные, типы, f-строки, isinstance |
| День 2 | Условия, циклы, range, input |
| День 3 | Функции, разделение ответственности |

## Запуск

```bash
python day3.py
```

## Команды бота

| Команда | Действие |
|---------|----------|
| `помощь` | Список команд |
| `версия` | Версия бота |
| `стоп` | Выход |
